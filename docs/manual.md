## V2.2 언어 전환 (KO / EN)

- 상단 앱 이름 오른쪽에 `KO` / `EN` 캡슐형 전환 스위치가 있습니다. Ultra Exif Reader와 같은 시각 디자인입니다.
- 한국어 브라우저는 한국어, 그 외 언어 브라우저는 영어로 처음 표시합니다. 사용자가 직접 선택하면 그 언어가 우선합니다.
- 브라우저 저장소(localStorage) 사용이 가능한 환경에서는 선택 언어를 저장하여 다음 실행에도 반영합니다. 브라우저 보안/사생활 보호 정책이 저장을 막을 수도 있습니다.
- 작업 중에 언어를 바꿔도 이미지 데이터, 저장 파일명, 사용자가 입력한 문구와 글꼴 선택값, 실행취소 기록은 그대로 유지됩니다.
- 메뉴·옵션·툴팁·상태 안내·AI 오류 알림·접근성 레이블이 함께 바뀝니다. 사용자 파일명과 폰트 이름은 실제 데이터로 보존합니다.
- 이 설명서는 한국어판입니다. 영어판은 [`manual_en.md`](manual_en.md)에서 볼 수 있습니다.

## 1. 앱 소개

Ultra PNG Studio V2.2은 웹 브라우저에서 실행되는 단일 HTML 이미지 편집 앱입니다.

주요 용도는 다음과 같습니다.

- 사진, 제품, 인물, 로고의 배경 제거
- 이미 투명한 PNG의 외곽선, 그림자, 색상, 방향, 크롭 편집
- 글자만 있는 투명 PNG 제작
- 투명 PNG, 미리보기 배경 포함 PNG, 흰 배경 JPG 저장
- 실행취소와 다시실행을 이용한 안전한 반복 편집

앱은 별도의 설치 프로그램 없이 HTML 파일을 브라우저에서 열어 사용합니다.
일반 이미지 편집과 저장은 브라우저 안에서 처리됩니다.

AI 배경 제거 기능은 처음 사용할 때 외부 CDN에서 AI 실행 라이브러리와 모델 데이터를
받아야 하므로 인터넷 연결이 필요합니다. 이미 브라우저 캐시에 저장된 뒤에는 환경에 따라
다음 실행이 더 빨라질 수 있습니다.

## 2. 실행 방법과 권장 환경

### 2-1. 실행 방법

1. 배포 ZIP의 압축을 풉니다.
2. HTML 파일을 더블클릭하거나 브라우저 창으로 끌어다 놓습니다.
3. 처음 화면에서 사용할 기능을 선택합니다.

권장 브라우저:

- 최신 Microsoft Edge
- 최신 Google Chrome
- 최신 Chromium 계열 브라우저

브라우저가 너무 오래되었거나 회사·학교 보안 정책으로 외부 CDN이 차단된 환경에서는
AI 배경 제거가 실행되지 않을 수 있습니다.

### 2-2. 파일을 열 때

배경 제거와 투명 이미지 편집 화면에서는 다음 방법으로 파일을 열 수 있습니다.

- 점선 드롭 영역을 클릭
- `파일 선택` 버튼 클릭
- 운영체제에서 이미지 파일을 점선 드롭 영역으로 드래그 앤 드롭

파일을 점선 영역 밖에 실수로 놓더라도 현재 페이지가 이미지 파일로 이동하지 않도록
보호되어 있습니다. 다만 파일을 실제로 불러오려면 지정된 점선 드롭 영역에 놓아야 합니다.

### 2-3. 지원 입력 형식

배경 제거 화면:

- PNG
- JPG / JPEG
- WEBP
- GIF
- BMP
- SVG
- AVIF

투명 이미지 편집 화면:

- PNG
- WEBP
- GIF
- AVIF
- 그 밖에 브라우저가 알파 채널을 지원하는 이미지

주의:

- 브라우저가 지원하지 않는 형식은 열리지 않을 수 있습니다.
- 애니메이션 GIF나 애니메이션 WEBP를 열어도 저장 결과는 정지 이미지입니다.
- SVG는 브라우저가 해석한 래스터 이미지로 편집됩니다.
- 크기(width/height) 없이 viewBox만 있는 SVG는 비율을 유지한 채 긴 변 2048px로 열립니다.
- 투명 이미지 편집은 알파 채널이 있는 파일에 가장 적합합니다.

## 3. 처음 화면과 공통 조작

### 3-1. 세 가지 작업 선택

처음 화면에는 다음 세 가지 기능이 표시됩니다.

#### 배경 제거
사진, 로고, 제품 이미지에서 주변 배경을 없애고 투명 PNG 또는 단색 배경 PNG로 저장합니다.

#### 투명 이미지 편집
이미 투명한 이미지를 열어 외곽선, 그림자, 색상, 회전, 반전, 크롭 등을 편집합니다.

#### 텍스트 PNG 만들기
원하는 글자를 투명 배경 이미지로 만든 뒤 외곽선과 그림자 등을 추가합니다.

### 3-2. 화면 이동 버튼

`← 작업 선택`
- 파일이나 텍스트를 아직 열기 전의 진입 화면에서 보입니다.
- 세 가지 기능을 고르는 첫 화면으로 돌아갑니다.
- 파일 선택 창을 열지 않습니다.

`⌂ 작업 선택`
- 편집 화면에서 현재 작업을 닫고 세 가지 기능 선택 화면으로 돌아갑니다.
- 현재 편집 기록은 종료됩니다.
- 파일 선택 창을 열지 않습니다.

`📂 다른 이미지`
- 배경 제거 또는 투명 이미지 편집 중에 다른 이미지 파일을 선택합니다.
- 새 이미지를 열면 이전 이미지의 실행취소 기록은 새 작업 기록으로 교체됩니다.

`🔤 텍스트 입력`
- 텍스트 PNG 편집 중 텍스트 입력 화면으로 돌아갑니다.
- 현재 텍스트 설정을 유지한 채 내용을 다시 확인하거나 수정할 수 있습니다.

### 3-3. 설정 패널

`⚙ 설정 패널` 버튼으로 오른쪽 설정 패널을 열거나 닫을 수 있습니다.

모바일이나 좁은 화면에서는 오른쪽 패널이 별도의 슬라이드 패널처럼 표시될 수 있습니다.
패널 오른쪽 위의 `✕` 버튼으로 닫을 수 있습니다.

### 3-4. 빠른 기능

상단 빠른 기능에는 현재 모드에서 자주 사용하는 토글이 표시됩니다.

`배경 제거`
- 배경 제거 모드에서만 표시됩니다.
- 켜면 현재 선택된 AI 또는 수동 방식으로 배경 제거 결과를 적용합니다.
- AI 방식을 선택했더라도 AI를 아직 실행하지 않았다면 원본 상태가 유지됩니다.

`그림자`
- 그림자를 빠르게 켜거나 끕니다.
- 투명 이미지가 흰색 또는 검은색 배경에서 묻힐 때 유용합니다.

### 3-5. 미리보기 배경

미리보기 배경은 투명 이미지가 실제 배경 위에서 어떻게 보이는지 확인하는 기능입니다.

선택 가능한 배경:

- 체크무늬: 투명 영역 확인
- 흰색
- 검정
- 어두운 회색
- 직접 선택한 색상
- 사용자 배경 이미지

중요:

- 미리보기 배경은 기본 `투명 PNG 저장` 결과에 포함되지 않습니다.
- `미리보기 화면 PNG 저장`을 사용하면 현재 미리보기 배경이 포함됩니다.
- 사용자 배경 이미지는 결과 합성용이 아니라 가시성 확인용입니다.

흰색, 검정, 체크 배경을 번갈아 확인하면 다음 문제를 쉽게 발견할 수 있습니다.

- 흰색 가장자리 잔재
- 검은색 테두리
- 반투명 얼룩
- 외곽선이 너무 굵은 문제
- 그림자가 너무 진하거나 넓은 문제

## 4. 배경 제거 상세 사용법

### 4-1. 기본 작업 순서

1. 처음 화면에서 `배경 제거`를 선택합니다.
2. 이미지를 점선 영역에 놓거나 `파일 선택`을 누릅니다.
3. 오른쪽 패널에서 AI 또는 수동 방식을 선택합니다.
4. 배경 제거 결과를 확인합니다.
5. 필요하면 경계, 잔재, 외곽선, 그림자, 색상 옵션을 조절합니다.
6. 체크·흰색·검정 배경에서 결과를 비교합니다.
7. `투명 PNG 저장` 또는 목적에 맞는 저장 버튼을 누릅니다.

사진, 인물, 복잡한 제품 사진은 AI 방식이 적합합니다.
단색 배경 로고, 스캔 이미지, 단순 제품 사진은 수동 방식이 더 빠르고 정확할 수 있습니다.

### 4-2. AI 자동 배경 제거

AI 방식 선택:

`🤖 AI 자동 배경 제거`
- 인물, 제품, 사물처럼 피사체와 배경이 복잡한 이미지에 권장합니다.
- 단색 배경이 아니어도 AI가 주요 피사체를 찾아 배경을 분리합니다.

실행 방법:

1. `AI 자동 배경 제거`를 선택합니다.
2. `🤖 AI 배경 제거 실행`을 누릅니다.
3. 첫 실행이라면 AI 라이브러리와 모델 다운로드가 진행됩니다.
4. 처리 완료 메시지가 나올 때까지 기다립니다.
5. 결과를 체크·흰색·검정 배경에서 확인합니다.

AI 실행 중 주의:

- AI 작업 중에는 실행취소, 다시실행, 처음 상태 복구가 잠깁니다.
- 처리 도중 새 이미지를 열면 이전 작업은 취소 또는 정리됩니다.
- 매우 큰 이미지는 브라우저 메모리 보호를 위해 AI 처리가 제한될 수 있습니다.
- AI 결과가 완벽하지 않으면 수동 방식으로 전환해 비교할 수 있습니다.

#### AI 경계 페더링: 0~24

AI가 만든 마스크의 안쪽 경계를 부드럽게 만듭니다.

- 0: AI 원래 경계를 그대로 사용
- 1~3: 작은 거친 경계를 살짝 부드럽게 함
- 4~8: 머리카락, 털, 부드러운 제품 가장자리에 유용
- 9~24: 고해상도 이미지에서 넓은 부드러움이 필요할 때 사용

값이 너무 높으면 피사체 가장자리 전체가 반투명해지거나 얇아질 수 있습니다.
먼저 2에서 확인하고 조금씩 높이는 방식이 안전합니다.

#### 단색 배경으로 채우기

AI가 제거한 투명 영역을 선택한 색상으로 채웁니다.

사용 예:

- 흰색 쇼핑몰 제품 이미지
- 검정 배경 썸네일
- 특정 브랜드 색상 배경
- 투명도를 지원하지 않는 용도

켜면 저장 버튼 문구가 단색 배경 저장에 맞게 변경됩니다.

주의:

- 단색 채우기를 켜면 결과의 바깥 배경은 투명하지 않습니다.
- 투명 배경이 필요하면 이 옵션을 끕니다.
- 흰색과 검정 빠른 버튼을 사용할 수 있고 색상 선택기로 다른 색을 지정할 수 있습니다.

### 4-3. 수동 배경색 제거

수동 방식 선택:

`🎨 수동 배경색 제거`
- 단색 배경
- 로고
- 스캔 이미지
- 균일한 스튜디오 배경
- 배경색이 명확한 제품 이미지

에 적합합니다.

수동 방식에는 세 가지 모드가 있습니다.

#### A. 스마트

선택한 배경색과 각 픽셀의 색상 거리를 계산해 투명도를 만듭니다.
단색 배경 로고에는 가장 먼저 시도할 수 있는 모드입니다.

주요 옵션:

`제거할 배경색`
- 제거하려는 배경색을 지정합니다.
- 검은 배경이면 검정, 흰 배경이면 흰색을 선택합니다.

`모서리 자동 감지`
- 이미지 네 모서리의 대표색을 계산해 배경색으로 지정합니다.
- 단색 배경 로고, 제품, 스캔 이미지에 유용합니다.
- 복잡한 사진이나 모서리에 피사체가 있는 이미지는 부정확할 수 있습니다.

`검출 감도: 1~255`
- 값이 높을수록 배경과 피사체를 더 넓은 범위로 구분합니다.
- 배경이 남으면 값을 높입니다.
- 피사체까지 많이 사라지면 값을 낮춥니다.

`배경색 완전 제거 범위: 0~50`
- 지정 배경색과 매우 가까운 픽셀을 완전히 투명하게 만드는 범위입니다.
- 배경색 얼룩이 남으면 값을 조금 높입니다.
- 피사체 테두리가 잘리면 낮춥니다.

`원본 색상 유지`
- ON: 남은 피사체의 원래 색을 유지합니다.
- OFF: 스마트 모드에서 남은 영역을 흰색 또는 검정 계열로 정리합니다.

권장:

- 컬러 로고, 사진, 제품: ON
- 흰색 단색 로고 또는 검은색 단색 로고: OFF도 시험 가능

#### B. 지정 색상

이미지 전체에서 지정한 배경색과 비슷한 픽셀을 제거합니다.

`허용 오차: 0~250`
- 값이 낮으면 지정 색상에 매우 가까운 부분만 제거합니다.
- 값이 높으면 더 넓은 색상 범위를 제거합니다.

적합한 경우:

- 이미지 전체의 같은 배경색을 모두 없애야 할 때
- 내부와 바깥쪽의 같은 색을 함께 제거해도 되는 경우

주의:

피사체 내부에도 같은 색상이 있다면 그 부분까지 제거될 수 있습니다.
그럴 때는 `가장자리 연결` 모드를 사용합니다.

#### C. 가장자리 연결

이미지 바깥 가장자리와 연결된 배경색 영역만 제거합니다.

`허용 오차: 0~250`
- 바깥 배경색 변화가 크면 높입니다.
- 피사체 가장자리까지 침범하면 낮춥니다.

적합한 경우:

- 피사체 내부에도 배경과 같은 색이 있음
- 바깥 배경만 제거하고 내부의 같은 색은 보존해야 함
- 구멍이나 글자 내부의 같은 색을 남겨야 함

### 4-4. 수동 배경 제거 공통 보정

`경계 페더링: 0~5`
- 배경 제거 경계에 부드러운 반투명 전환을 만듭니다.
- 0은 페더링 없음입니다.
- 1~2는 작은 거친 가장자리에 적합합니다.
- 너무 높으면 가는 선이나 작은 글자가 흐려질 수 있습니다.

`희미한 잔재 제거: 0~64`
- 배경색이 반투명 얼룩처럼 남은 부분을 제거합니다.
- 체크 배경에서 점이나 먼지처럼 보이는 잔재가 있으면 높입니다.
- 가는 선이나 작은 디테일이 사라지면 낮춥니다.

`경계 매끄럽게: 0~4`
- 알파 경계의 계단 현상을 부드럽게 합니다.
- 0은 원래 경계에 가깝습니다.
- 0.7~1.8 정도에서 먼저 조절하는 것이 안전합니다.
- 너무 높으면 가는 선이나 글자 테두리가 얇아질 수 있습니다.

### 4-5. 수동 제거 프리셋

프리셋 버튼은 추천 설정을 빠르게 적용합니다.
같은 그룹의 다른 프리셋을 누르면 그 그룹의 기존 프리셋이 교체됩니다.
적용된 프리셋을 다시 누르면 해제됩니다.

`검은 배경 → 흰 로고`
- 검은 배경 위 흰색 로고나 글자에 적합합니다.
- 검정 배경을 제거하고 흰색 주체를 정리합니다.

`흰 배경 → 검은 로고`
- 흰 배경 위 검은 로고나 글자에 적합합니다.

`컬러 로고 보존`
- 컬러 로고의 원래 색상을 가능한 한 유지합니다.
- 자동으로 모서리 배경색을 참고할 수 있습니다.

`강한 잔재 제거`
- 희미한 배경 찌꺼기가 많이 남을 때 사용합니다.
- 가는 선이 사라질 수 있으므로 결과를 확대해 확인합니다.

`부드러운 경계`
- 거친 경계를 부드럽게 정리할 때 사용합니다.
- 아주 작은 글자나 얇은 로고에서는 지나치게 부드러워질 수 있습니다.

프리셋 사용 후 슬라이더를 직접 조절하면 프리셋 표시가 해제될 수 있습니다.
이는 현재 값이 더 이상 프리셋의 고정 조합과 같지 않다는 의미입니다.

### 4-6. 배경 제거 결과가 좋지 않을 때

사진에서 AI가 피사체 일부를 놓침:
- AI 경계 페더링을 먼저 낮춰 봅니다.
- 원본의 피사체와 배경 대비가 너무 낮으면 다른 원본을 사용합니다.
- 작은 피사체가 여러 개 있으면 AI가 일부만 선택할 수 있습니다.

로고 바깥에 흰색 또는 검은색 테두리가 남음:
- `희미한 잔재 제거`를 조금 높입니다.
- `배경색 완전 제거 범위`를 조금 높입니다.
- `경계 매끄럽게`를 소폭 조절합니다.
- 흰색과 검정 미리보기 배경에서 번갈아 확인합니다.

피사체 가장자리가 잘림:
- 검출 감도, 허용 오차, 완전 제거 범위를 낮춥니다.
- 잔재 제거 값을 낮춥니다.
- 페더링과 매끄럽게 값을 낮춥니다.
- 컬러 이미지라면 `원본 색상 유지`를 켭니다.

피사체 내부의 같은 색도 사라짐:
- `지정 색상` 대신 `가장자리 연결`을 사용합니다.

## 5. 투명 이미지 편집 상세 사용법

### 5-1. 기본 작업 순서

1. 처음 화면에서 `투명 이미지 편집`을 선택합니다.
2. 알파 채널이 있는 이미지를 엽니다.
3. 체크무늬 배경에서 투명 영역을 확인합니다.
4. 흰색과 검정 배경에서 외곽선과 그림자를 비교합니다.
5. 외곽선, 그림자, 가시성 보정, 회전, 반전을 조절합니다.
6. 필요하면 투명 여백을 자동으로 자릅니다.
7. `투명 PNG 저장`으로 저장합니다.

이 모드는 배경을 새로 제거하는 화면이 아니라,
이미 투명한 이미지의 모양과 가시성을 개선하는 화면입니다.

### 5-2. 불투명 이미지 안내

투명 이미지 편집 모드에서 의미 있는 투명 영역이 없는 이미지를 열면 안내창이 나타납니다.

`현재 이미지 그대로 편집`
- 불투명 이미지를 현재 화면에서 그대로 편집합니다.
- 기본 그림자는 자동으로 꺼져 있습니다.
- 불투명 직사각형 주변에 그림자 테두리가 생기는 혼동을 줄이기 위한 안전 동작입니다.

`배경 제거 화면으로 이동`
- 현재 이미지를 유지한 채 배경 제거 모드로 이동합니다.
- 같은 파일을 다시 선택할 필요가 없습니다.

안내창의 `×`를 누르거나 Escape 키를 누르면 현재 이미지 그대로 편집할 수 있습니다.

### 5-3. 투명 이미지에 외곽선을 사용하는 방법

외곽선은 투명 로고나 글자가 특정 배경에서 보이지 않을 때 유용합니다.

예:

- 흰색 로고가 흰 배경에서 안 보임 → 검은 외곽선
- 검은 로고가 검은 배경에서 안 보임 → 흰 외곽선
- 밝고 어두운 여러 배경에서 모두 사용 → 얇은 반대색 외곽선과 약한 그림자

권장 시작값:

- 작은 아이콘·로고: 2~4
- 큰 로고: 4~8
- 매우 두꺼운 스티커 느낌: 8 이상

외곽선이 잘리는 경우:
- `투명 여백 자동 자르기`의 여백 값을 높입니다.
- 자동 자르기를 끄고 저장 결과를 확인합니다.

### 5-4. 투명 이미지에 그림자를 사용하는 방법

그림자는 주체를 배경에서 분리해 보이게 합니다.

주요 옵션:

`블러 범위: 0~120`
- 낮을수록 딱딱하고 선명한 그림자
- 높을수록 넓고 부드러운 그림자

`강도: 0~100%`
- 그림자 불투명도
- 너무 높으면 이미지가 탁하거나 무거워 보일 수 있습니다.

`가로 이동: -30~30`
- 음수: 왼쪽
- 양수: 오른쪽

`세로 이동: -30~30`
- 음수: 위
- 양수: 아래

`그림자 색상`
- 일반 그림자는 검정 또는 짙은 색이 자연스럽습니다.
- 밝은 글로우는 흰색이나 밝은 색을 사용할 수 있습니다.

빠른 프리셋:

`소프트 글로우`
- 밝은 색의 부드러운 빛을 이미지 주변에 만듭니다.

`외곽선·그림자 끄기`
- 두 효과를 모두 제거해 순수한 원본 알파 이미지를 확인합니다.

### 5-5. 투명 이미지 편집에서 주의할 점

- 원래 투명도는 기본적으로 유지됩니다.
- 전체 불투명도를 낮추면 원래 알파와 함께 전체 이미지가 더 투명해집니다.
- 그림자나 외곽선을 추가한 뒤 자동 자르기 여백이 너무 작으면 효과가 잘릴 수 있습니다.
- 투명 이미지를 JPG로 저장하면 흰 배경과 합쳐지므로 투명도가 사라집니다.
- `미리보기 화면 PNG 저장`은 현재 선택한 미리보기 배경까지 포함합니다.

## 6. 텍스트 PNG 만들기 상세 사용법

### 6-1. 처음 텍스트 만들기

1. 처음 화면에서 `텍스트 PNG 만들기`를 선택합니다.
2. 텍스트 내용을 입력합니다.
3. 글자 크기를 선택합니다.
4. 글자 색상을 선택합니다.
5. 글꼴을 선택합니다.
6. 볼드와 이탤릭을 설정합니다.
7. `텍스트 PNG 생성`을 누릅니다.

입력 제한:

- 텍스트는 160자 이하를 권장하며 앱도 160자로 제한합니다.
- 글자 크기는 24~512 범위입니다.
- 빈 텍스트는 생성할 수 없습니다.
- 글자 수와 크기가 지나치게 크면 캔버스 안전 제한으로 생성이 중단될 수 있습니다.

### 6-2. 글자 색상 선택

`색상 선택` 버튼을 누르면 빠른 색상 팔레트가 열립니다.

색상 선택 방법:

- 빠른 색상칩 선택
- HEX 값 직접 입력
- `🎨` 버튼으로 브라우저 기본 색상 선택기 열기

HEX 입력 예:

- 흰색: #FFFFFF
- 검정: #000000
- 빨강: #FF0000
- 파랑: #0066FF

어두운 색을 선택하더라도 입력창 안에서는 글자를 읽을 수 있도록
밝은 대비 효과가 표시됩니다. 이 대비 효과는 입력창 전용이며,
실제 생성되는 텍스트 PNG에는 추가되지 않습니다.

### 6-3. 기본 글꼴

환경에 따라 다음과 같은 시스템 글꼴을 선택할 수 있습니다.

- 맑은 고딕
- 궁서
- 바탕
- 굴림
- 돋움
- Segoe UI
- Arial
- Verdana
- Georgia
- Impact
- Consolas
- 기타 목록에 표시되는 글꼴

주의:

선택한 글꼴이 운영체제에 설치되어 있지 않으면 브라우저가 비슷한 대체 글꼴을 사용할 수 있습니다.

### 6-4. 커스텀 폰트 사용

`커스텀 폰트 불러오기` 버튼으로 직접 폰트 파일을 선택할 수 있습니다.

지원 확장자:

- TTF
- OTF
- WOFF
- WOFF2

여러 폰트 선택:

- Ctrl 또는 Shift를 이용해 여러 파일 선택
- 파일 선택창에서 Ctrl+A 사용 가능

중요:

- 앱은 특정 `fonts` 폴더를 자동 검색하지 않습니다.
- 사용자가 폰트 파일을 직접 선택해야 합니다.
- 여러 폰트를 목록에 추가하더라도 실제로 선택한 폰트만 로드됩니다.
- 브라우저를 닫거나 페이지를 새로 열면 커스텀 폰트를 다시 선택해야 할 수 있습니다.
- 폰트 파일 자체는 PNG에 포함되지 않으며, 렌더링된 글자 모양만 이미지에 저장됩니다.
- 배포본에는 폰트 파일이 들어 있지 않습니다. 추천 폰트와 받는 곳은 `README.md`의 "추천 폰트" 항목을 참고합니다.

### 6-5. 볼드와 이탤릭

`볼드`
- 글자를 굵게 표시합니다.
- 일부 폰트는 실제 굵은 글꼴이 없어 브라우저가 굵기를 모사할 수 있습니다.

`이탤릭`
- 글자를 기울입니다.
- 일부 한글 폰트는 이탤릭 모양이 자연스럽지 않을 수 있습니다.

텍스트 입력창에도 현재 글꼴, 색상, 볼드, 이탤릭 모양이 반영되어
생성 전 대략적인 느낌을 확인할 수 있습니다.

### 6-6. 생성 후 실시간 텍스트 편집

텍스트 PNG를 생성하면 오른쪽 패널에 `텍스트 편집` 영역이 나타납니다.

다음 항목은 변경 즉시 결과 이미지에 반영됩니다.

- 텍스트 내용
- 글자 크기
- 글자 색상
- 글꼴
- 볼드
- 이탤릭

상태 배지:

`LIVE · 변경 즉시 반영`
- 현재 텍스트 변경이 결과 이미지에 즉시 적용된다는 뜻입니다.

160자를 초과하면:
- 실시간 미리보기가 일시 중지됩니다.
- 텍스트를 다시 160자 이하로 줄이면 갱신이 재개됩니다.

글자 크기 입력:
- 24 미만 입력 후 편집을 확정하면 24로 정리됩니다.
- 512 초과 입력 후 편집을 확정하면 512로 정리됩니다.
- 비어 있거나 올바르지 않은 값은 200으로 정리됩니다.

### 6-7. 텍스트 PNG에 외곽선과 그림자 추가

흰색 글자:
- 검은 배경에서도 보이지만 흰 배경에서는 사라질 수 있습니다.
- 검은 외곽선 또는 검은 그림자를 추가합니다.

검은색 글자:
- 흰 배경에서는 잘 보이지만 검은 배경에서는 사라질 수 있습니다.
- 흰 외곽선 또는 흰색 소프트 글로우를 추가합니다.

스티커 글자:
- 두꺼운 흰색 외곽선
- 약한 검은 그림자
- 자동 자르기 여백을 충분히 확보

네온 느낌:
- 선명한 글자색
- 같은 계열 또는 흰색 소프트 글로우
- 그림자 이동은 0에 가깝게 설정

텍스트 생성 당시의 기본 텍스트 소스와
그 뒤에 적용한 외곽선·그림자·회전·출력 설정은 서로 구분되어 관리됩니다.

## 7. 외곽선·그림자·색상·변환 옵션

### 7-1. 외곽선 / 글로우

`외곽선 사용`
- 외곽선 효과를 켜거나 끕니다.

`외곽선 두께: 0~24`
- 0은 외곽선이 보이지 않습니다.
- 값이 높을수록 굵어집니다.

`외곽선 색상`
- 흰색, 검정 또는 임의 색상을 선택합니다.

빠른 버튼:

`흰 외곽선`
- 흰색 외곽선과 권장 두께를 적용합니다.

`검은 외곽선`
- 검은색 외곽선과 권장 두께를 적용합니다.

`소프트 글로우`
- 이동이 거의 없는 밝고 부드러운 그림자를 적용합니다.

`외곽선·그림자 끄기`
- 외곽선과 그림자를 함께 끕니다.

### 7-2. 가시성 보정

`전체 불투명도: 0~100%`
- 100%는 원래 불투명도
- 낮출수록 전체 결과가 투명해집니다.

`밝기: 0~200%`
- 100%가 원본
- 낮추면 어두워지고 높이면 밝아집니다.

`대비: 0~200%`
- 100%가 원본
- 높이면 밝고 어두운 부분의 차이가 커집니다.

`채도: 0~200%`
- 100%가 원본
- 0%는 회색조에 가까움
- 높이면 색이 더 선명해집니다.

이 값들은 미리보기뿐 아니라 최종 저장 이미지에도 적용됩니다.

### 7-3. 변환

`회전: 0~360°`
- 이미지를 자유롭게 회전합니다.
- 회전으로 바깥 영역이 커지므로 자동 자르기와 함께 확인합니다.

`좌우 반전`
- 가로 방향을 뒤집습니다.

`상하 반전`
- 세로 방향을 뒤집습니다.

회전과 반전은 외곽선, 그림자, 색상 보정과 함께 결과에 적용됩니다.

### 7-4. 타일 미리보기

타일 미리보기는 배경 제거 모드에서 사용할 수 있습니다.

`반복 배치 확인`
- 현재 투명 이미지를 여러 개 반복 배치한 모습을 미리 보여줍니다.

`타일 크기`
- 반복 이미지의 상대 크기를 조절합니다.

`타일 간격`
- 타일 사이 간격을 조절합니다.

`타일 각도`
- 반복 이미지의 회전 각도를 조절합니다.

중요:

- 타일은 미리보기 전용입니다.
- `투명 PNG 저장` 결과는 단일 이미지입니다.
- 타일 화면 자체를 저장하려면 `미리보기 화면 PNG 저장`을 사용합니다.

## 8. 미리보기와 저장 방식

### 8-1. 투명 여백 자동 자르기

`투명 여백 자동 자르기`
- 이미지 주변의 완전히 투명한 빈 공간을 잘라냅니다.
- 로고, 스티커, ComfyUI 입력용 PNG 등에 유용합니다.

`자동 자르기 여백: 0~160`
- 잘라낸 피사체 주변에 남길 투명 여백입니다.
- 외곽선이나 그림자가 잘리면 값을 높입니다.
- 결과를 최대한 타이트하게 만들려면 낮춥니다.

주의:

- 그림자 범위가 크면 여백도 충분히 남겨야 합니다.
- 단색 AI 배경 채우기를 사용하는 경우에도 피사체 위치를 기준으로 자르기가 계산됩니다.

### 8-2. 정사각형으로 맞추기

`정사각형으로 맞추기`
- 결과를 정사각형 캔버스 중앙에 배치합니다.
- 프로필 이미지, 아이콘, 스티커, 데이터셋 이미지에 유용합니다.

동작:

1. 자동 자르기가 켜져 있으면 먼저 투명 영역을 기준으로 자릅니다.
2. 가로와 세로 중 긴 변을 정사각형 한 변으로 사용합니다.
3. 결과를 중앙에 배치합니다.

안전 동작:

정사각형 결과가 너무 커서 메모리 제한을 넘으면 저장 전체를 중단하지 않고
정사각형 맞추기만 자동으로 건너뛰며 원래 비율로 저장합니다.

### 8-3. 저장 버튼 차이

`⬇ 투명 PNG 저장`
- 투명도가 포함된 기본 결과를 저장합니다.
- 최종 투명 파일은 이 버튼을 사용합니다.
- 단색 AI 배경 채우기가 켜져 있으면 버튼 문구가 단색 배경 저장에 맞게 바뀔 수 있습니다.
- AI 방식에서 AI를 아직 실행하지 않았다면 원본 상태가 저장된다는 안내가 표시됩니다.

`⬇ 미리보기 화면 PNG 저장`
- 현재 왼쪽 화면에 표시되는 미리보기 배경까지 포함해 저장합니다.
- 체크무늬, 흰색, 검정, 사용자 색상 또는 사용자 배경 이미지가 포함될 수 있습니다.
- 투명 PNG가 아닐 수 있습니다.
- 타일 미리보기 화면을 저장할 때 사용합니다.

`⬇ 흰 배경 JPG 저장`
- 결과를 흰색 배경과 합성해 JPG로 저장합니다.
- JPG는 투명도를 지원하지 않습니다.
- 웹 게시나 문서 삽입용 확인 이미지에 적합합니다.

저장 파일 이름은 원본 파일 이름을 바탕으로 만들어집니다. 예를 들어 `photo.jpg`를 열었다면:

- photo_nobg.png — 배경 제거 결과
- photo_solid_bg.png — 단색 배경으로 채운 결과
- photo_edited.png — 투명 이미지 편집 결과
- photo_edit.png — 배경 제거를 적용하지 않은 상태 (원본과 이름 구분)
- photo_nobg_preview_bg.png — 미리보기 화면 저장
- photo_nobg_tile_preview.png — 타일 미리보기 저장
- photo_nobg_check_white_bg.jpg — 흰 배경 JPG 저장

텍스트 PNG는 `text_image.png`(단색 배경이면 `solid_bg_text_image.png`)로 저장됩니다.
같은 이름의 파일이 이미 있으면 브라우저의 다운로드 설정에 따라 `(1)`, `(2)` 등 중복 방지 번호가 붙을 수 있습니다.

## 9. 실행취소·다시실행·처음 상태 복구

### 9-1. 실행취소와 다시실행

버튼:

- `↶ 실행취소`
- `↷ 다시실행`

단축키:

- Ctrl+Z: 실행취소
- Ctrl+Y: 다시실행
- Ctrl+Shift+Z: 다시실행

동작 특징:

- 옵션 설정과 이미지 결과가 함께 이전 상태로 돌아갑니다.
- 슬라이더를 계속 끌어 조절한 동작은 한 단계로 묶입니다.
- 최대 40단계의 기록을 유지합니다.
- AI 배경 제거 완료 결과도 실행취소할 수 있습니다.
- 새 이미지를 열거나 새 텍스트 작업을 만들면 새 작업 기준으로 기록이 초기화됩니다.
- 기록이 없을 때 실행취소·다시실행 버튼은 숨겨집니다.
- AI 작업 중에는 버튼이 잠깁니다.

AI 작업 완료도 하나의 편집 단계입니다.
따라서 AI 처리 중 다른 옵션을 먼저 바꾸고 AI가 나중에 완료되면,
첫 번째 실행취소는 가장 나중에 완료된 AI 결과를 되돌릴 수 있습니다.

### 9-2. 처음 상태 복구

`↺ 처음 상태 복구`는 앱의 첫 화면으로 나가는 버튼이 아닙니다.
현재 소스를 유지하면서 현재 모드의 편집 상태를 처음 작업 상태로 되돌립니다.

## 10. 이미지 크기와 안전 제한

브라우저가 과도한 메모리를 사용해 멈추거나 탭이 종료되는 일을 줄이기 위해
다음 안전 제한이 적용됩니다.

- 무거운 픽셀 연산: 32MP
- 원본 이미지 열기: 48MP
- 일반 렌더링 및 분석 캔버스: 64MP
- 최종 내보내기 캔버스: 96MP
- 캔버스 한 변 최대: 16,384px

제한의 의미:

#### 32MP 초과
- 일부 고비용 기능이 실행되지 않을 수 있습니다.
- AI 처리, 수동 픽셀 처리, 외곽선 등 기능별로 안전 안내가 나타날 수 있습니다.

#### 48MP 초과
- 원본 이미지 열기가 차단될 수 있습니다.

#### 64MP 초과
- 효과를 포함한 미리보기 렌더링이 제한될 수 있습니다.

#### 96MP 초과
- 최종 저장 이미지 생성이 제한될 수 있습니다.

#### 16,384px 초과
- 가로나 세로 중 한 변이 이 값을 넘으면 캔버스를 만들지 않습니다.

정사각형 맞추기만 제한을 넘는 경우:
- 저장 전체를 막지 않습니다.
- 정사각형 출력을 자동으로 건너뛰고 원래 비율로 저장합니다.

큰 이미지 사용 팁:

- 원본을 먼저 적당한 크기로 축소합니다.
- 매우 넓은 그림자와 두꺼운 외곽선을 줄입니다.
- 자동 자르기를 사용해 불필요한 빈 공간을 제거합니다.
- 정사각형 맞추기가 꼭 필요하지 않으면 끕니다.
- 브라우저의 다른 무거운 탭을 닫습니다.

## 11. 자주 사용하는 작업 예시

### 11-1. 검은 배경의 흰색 로고를 투명 PNG로 만들기

1. `배경 제거` 선택
2. 로고 이미지 열기
3. `수동 배경색 제거` 선택
4. `검은 배경 → 흰 로고` 프리셋 선택
5. 체크 배경에서 잔재 확인
6. 검은 테두리가 남으면 `희미한 잔재 제거`를 조금 높임
7. 흰색 로고가 너무 얇아지면 값을 다시 낮춤
8. 자동 자르기 ON
9. 여백 8~24 정도 확인
10. `투명 PNG 저장`

### 11-2. 흰 배경 제품 사진의 배경 제거

단순하고 균일한 흰 배경:

1. 수동 방식 선택
2. 모서리 자동 감지 또는 흰색 선택
3. 스마트 모드로 시작
4. 컬러 제품이면 원본 색상 유지 ON
5. 검출 감도와 완전 제거 범위를 조금씩 조절
6. 어려우면 AI 방식과 비교

복잡한 그림자나 배경 변화가 있는 사진:

1. AI 방식 선택
2. AI 배경 제거 실행
3. 경계 페더링 2에서 확인
4. 필요한 경우 3~8 사이로 조절
5. 체크·검정 배경에서 가장자리 확인

### 11-3. 투명 로고를 모든 배경에서 잘 보이게 만들기

1. `투명 이미지 편집`으로 로고 열기
2. 체크·흰색·검정 배경 비교
3. 로고가 흰색이면 검은 외곽선
4. 로고가 검은색이면 흰 외곽선
5. 외곽선 두께 2~4부터 시작
6. 필요하면 약한 그림자 추가
7. 자동 자르기 여백을 외곽선보다 넉넉하게 설정
8. 투명 PNG 저장

### 11-4. 스티커 스타일 텍스트 PNG 만들기

1. 텍스트 PNG 만들기
2. 굵은 글꼴과 볼드 사용
3. 글자색 선택
4. 텍스트 PNG 생성
5. 흰 외곽선 또는 검은 외곽선 적용
6. 외곽선 두께 4~8 조절
7. 약한 검은 그림자 추가
8. 자동 자르기 ON
9. 여백 16~40 조절
10. 투명 PNG 저장

### 11-5. 흰 배경 쇼핑몰 제품 이미지 만들기

1. AI 배경 제거 실행
2. 결과 확인
3. `단색 배경으로 채우기` ON
4. 채울 배경색을 흰색으로 선택
5. 자동 자르기와 여백 조절
6. 필요하면 정사각형 맞추기 ON
7. 단색 배경 PNG 저장

### 11-6. 반복 패턴 느낌 확인하기

1. 배경 제거 결과 준비
2. `세부 옵션 더 보기`
3. `반복 배치 확인` ON
4. 타일 크기, 간격, 각도 조절
5. 화면용 결과가 필요하면 `미리보기 화면 PNG 저장`
6. 단일 원본 투명 PNG가 필요하면 `투명 PNG 저장`

## 12. 문제 해결

### 12-1. AI 배경 제거가 시작되지 않음

확인할 사항:

- 인터넷 연결 확인
- CDN 차단 여부 확인
- 최신 Edge 또는 Chrome 사용
- 브라우저 새로고침 후 재시도
- 보안 프로그램이 외부 스크립트와 모델 파일을 막는지 확인
- 이미지가 너무 큰지 확인

처음 실행은 AI 라이브러리와 모델을 받기 때문에 시간이 더 걸릴 수 있습니다.

실패하면 상태 표시에 원인이 구분되어 나타납니다.

- `인터넷 연결이 끊겨 있습니다` — 네트워크 연결을 확인합니다.
- `AI 라이브러리를 불러오지 못했습니다(cdn.jsdelivr.net)` — 보안 프로그램이나 회사·학교 방화벽이 CDN을 막는지 확인합니다.
- `AI 모델 데이터를 내려받지 못했습니다(staticimgly.com)` — 모델 서버 접속이 막혔는지 확인합니다.
- `메모리가 부족합니다` — 이미지 크기를 줄이거나 다른 탭을 닫습니다.

AI를 사용할 수 없는 환경에서도 수동 배경색 제거는 그대로 사용할 수 있습니다.

### 12-2. AI 버튼이 계속 처리 중으로 보임

- 잠시 기다린 뒤 완료 메시지를 확인합니다.
- 새 이미지를 연 직후라면 이전 AI 작업 정리가 끝날 때까지 기다립니다.
- 탭이 실제로 멈춘 경우 브라우저를 다시 열어야 할 수 있습니다.
- 너무 큰 이미지는 축소한 뒤 다시 시도합니다.

### 12-3. 저장 버튼을 눌러도 파일이 저장되지 않음

- 브라우저의 여러 파일 다운로드 차단 확인
- 저장할 이미지가 실제로 열려 있는지 확인
- 이미지가 너무 커 내보내기 제한을 넘었는지 확인
- 자동 자르기나 정사각형 설정을 줄여 재시도
- 다운로드 폴더 권한과 디스크 공간 확인

### 12-4. 투명 PNG로 저장했는데 배경이 보임

가능한 원인:

- AI 단색 배경 채우기가 켜져 있음
- 배경 제거 토글이 꺼져 있음
- AI 방식을 선택했지만 AI 실행을 하지 않음
- `미리보기 화면 PNG 저장`을 사용함
- JPG로 저장함

해결:

- 단색 배경 채우기 OFF
- 배경 제거 ON
- AI 실행 완료 확인
- `투명 PNG 저장` 사용

### 12-5. 가장자리가 하얗거나 검게 남음

- 희미한 잔재 제거를 조금 높임
- 완전 제거 범위 또는 허용 오차를 조금 높임
- 다른 수동 제거 모드와 비교
- AI 경계 페더링을 조절
- 흰색·검정 미리보기 배경에서 각각 확인

### 12-6. 가는 선이나 머리카락이 사라짐

- 검출 감도 낮추기
- 허용 오차 낮추기
- 완전 제거 범위 낮추기
- 희미한 잔재 제거 낮추기
- 경계 매끄럽게 낮추기
- 페더링 낮추기
- 컬러 이미지라면 원본 색상 유지 ON
- 수동 방식 대신 AI 방식 시험

### 12-7. 투명 이미지 편집에서 사각형 그림자가 보임

불투명 이미지를 투명 이미지 편집 모드에서 연 경우일 수 있습니다.

- 안내창의 `배경 제거 화면으로 이동` 선택
- 또는 그림자 OFF
- 불투명 이미지에서는 기본 그림자가 자동으로 꺼집니다.

### 12-8. 커스텀 폰트가 목록에 없거나 적용되지 않음

- 지원 확장자인지 확인: TTF, OTF, WOFF, WOFF2
- 커스텀 폰트 불러오기로 다시 선택
- 파일이 손상되었는지 확인
- 브라우저를 바꾸어 확인
- 글꼴 선택 목록에서 실제로 해당 폰트를 선택했는지 확인
- 폰트 로딩이 끝난 뒤 미리보기를 확인

### 12-9. 검은 글자를 선택하니 입력창에서 안 보임

현재 배포본은 어두운 글자색에 밝은 입력 전용 대비 효과를 자동 적용합니다.
실제 PNG에는 이 대비 효과가 들어가지 않습니다.

그래도 보기 어렵다면:

- 글자색 팔레트를 닫았다 다시 열기
- 다른 색을 선택한 뒤 검정으로 다시 선택
- 브라우저 확대 비율을 100%로 확인

### 12-10. 글자 크기 값이 자동으로 바뀜

글자 크기는 안전 범위 24~512로 제한됩니다.

- 24 미만 → 24
- 512 초과 → 512
- 빈 값 또는 올바르지 않은 값 → 200

### 12-11. 자동 자르기 후 외곽선이나 그림자가 잘림

- 자동 자르기 여백을 높입니다.
- 그림자 블러와 이동 값을 줄입니다.
- 외곽선 두께를 줄입니다.
- 자동 자르기를 끈 결과와 비교합니다.

### 12-12. 정사각형으로 저장되지 않음

정사각형 결과가 메모리 안전 한도를 넘으면 앱이 자동으로 원래 비율을 유지합니다.

해결:

- 원본 이미지 축소
- 자동 자르기 사용
- 여백 줄이기
- 외곽선과 그림자 범위 줄이기

### 12-13. 실행취소 버튼이 보이지 않음

- 아직 기록된 변경이 없으면 버튼 영역이 숨겨집니다.
- 슬라이더나 옵션을 변경하면 필요한 버튼이 나타납니다.
- 새 작업을 시작하면 이전 기록은 초기화됩니다.
- AI 실행 중에는 실행취소·다시실행이 잠깁니다.

### 12-14. 작업 선택을 눌렀는데 파일 선택창이 열리지 않음

정상 동작입니다.

`작업 선택`은 세 가지 기능을 고르는 첫 화면으로 이동하는 버튼입니다.
다른 파일을 열려면 편집 화면의 `📂 다른 이미지` 또는 진입 화면의 `파일 선택`을 사용합니다.

## 13. 배포 및 보관 시 참고 사항
14. KO/EN 화면 전환 (V2.2)

- HTML 파일과 이 설명서를 같은 폴더에 두면 사용자가 찾기 쉽습니다.
- 앱은 커스텀 폰트 폴더를 자동으로 읽지 않으며, 폰트 파일은 배포본에 포함되어 있지 않습니다.
- 사용할 폰트는 각 제작처의 공식 경로에서 받아 `커스텀 폰트 불러오기`로 선택합니다. 폰트마다 재배포 조건이 다르므로 폰트 파일을 다시 배포할 때는 해당 라이선스를 확인합니다.
- 이 앱은 GNU AGPL-3.0 라이선스로 배포됩니다. AI 배경 제거에 사용하는 IMG.LY Background Removal 라이브러리도 AGPL-3.0입니다(`THIRD_PARTY_NOTICES.md` 참고).
- AI 기능은 외부 CDN 연결이 필요합니다.
- 일반 편집 파일은 브라우저 안에서 처리되며 앱 코드에는 별도 서버 업로드 기능이 없습니다.
- 브라우저 캐시와 보안 설정에 따라 첫 AI 실행 시간이 달라질 수 있습니다.
- 원본 파일은 직접 덮어쓰지 않고 새 다운로드 파일로 저장됩니다.
- 중요한 작업은 최종 PNG뿐 아니라 원본 이미지도 별도로 보관하는 것이 좋습니다.
- 새 버전을 배포할 때는 이전 HTML과 섞지 말고 버전별 폴더 또는 ZIP으로 보관하는 것이 안전합니다.

## 빠른 요약

배경 제거:
이미지 열기 → AI 또는 수동 선택 → 경계 보정 → 여러 배경에서 확인 → 투명 PNG 저장

투명 이미지 편집:
투명 이미지 열기 → 외곽선·그림자·색상·회전 조절 → 자동 자르기 → 투명 PNG 저장

텍스트 PNG:
텍스트·크기·색상·폰트 설정 → 텍스트 PNG 생성 → 실시간 편집 → 외곽선·그림자 → 저장

가장 중요한 저장 구분:
- 투명도가 필요함: 투명 PNG 저장
- 현재 배경까지 포함: 미리보기 화면 PNG 저장
- 흰 배경 일반 이미지: 흰 배경 JPG 저장

문제가 생겼을 때:
- 실행취소: Ctrl+Z
- 다시실행: Ctrl+Y 또는 Ctrl+Shift+Z
- 현재 소스 유지 후 효과 초기화: 처음 상태 복구
- 현재 작업을 닫고 첫 화면으로 이동: 작업 선택


### V2.2 배포 전 보완 사항

- 글꼴 파일은 ZIP에 포함하지 않으며, 기존 `커스텀 폰트 불러오기`로 사용자 PC의 TTF/OTF/WOFF/WOFF2를 직접 선택할 수 있습니다.
- 유효한 viewBox만 있는 SVG는 긴 변 2048px로 처리합니다. width 또는 height 한쪽만 픽셀 값으로 지정되었다면 해당 값을 우선하고 viewBox 비율로 반대편 크기를 계산합니다. 두 크기가 지정된 SVG는 원래 크기를 사용합니다.
- 배경 제거를 실행하지 않은 원본 저장은 `_edit` 접미사를 붙입니다. 텍스트 PNG 모드 저장명은 기존과 같습니다.
- AI 오류를 입력 준비, 모듈 로딩, 모델 처리, 결과 이미지 읽기 등의 단계로 구분해 알림과 상태 표시를 제공합니다. 오류 원인이 불확실하면 가능성을 안내하며, 실제 모델 동작은 사용자의 환경에서 확인해야 합니다.
- 첫 화면에서 AGPL-3.0 라이선스 전문 및 외부 구성요소 고지로 이동할 수 있습니다.

2. 한국어와 영어 화면 사이를 자유롭게 이동해도 현재 편집 중인 사진, 텍스트 내용, 선택된 폰트, AI 결과 및 Undo/Redo 기록은 유지됩니다.

이 기능은 앱 화면의 UI 언어만 전환합니다. 이미지 속 문구나 외부 파일 내용을 자동 번역하는 기능은 아닙니다.
