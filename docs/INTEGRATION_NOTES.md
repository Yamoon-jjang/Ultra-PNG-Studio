# Ultra PNG Studio v2.2 — 수정 범위 / Integration Notes

**기준:** 직전 통합 검증본의 이미지 처리·AI 실행 엔진을 유지하며 KO/EN 화면 레이어만 추가. 저장소의 유일한 런타임 파일은 `index.html`입니다.

- **UI:** Ultra Exif Reader의 검증된 캡슐형 KO/EN 스위치 스타일(금빛 활성 테두리·키보드 포커스 지원)을 상단 제목 옆에 배치.
- **언어 정책:** 한국어 브라우저는 KO, 그 외 언어는 EN 기본값. 사용자가 선택한 언어는 localStorage가 허용하는 범위에서 기억. `html lang`, `aria-pressed` 동기화.
- **적용 범위:** 랜딩 화면, 모드별 버튼·설정·옵션, 툴팁, 접근성 속성, 동적으로 출력되는 상태·오류·안내 문구 등.
- **데이터 보호:** 입력 `<textarea>`·사용자 텍스트, 원본 이미지/파일명, 폰트 파일 이름·가족 내부 값, 캔버스·이미지 결과는 번역하지 않음. 번역 문자열은 UI 텍스트 노드 및 관련 속성에만 적용하며, 편집 작업을 초기화하거나 재실행하지 않음.
- **동적 UI:** 변화한 문구만 관찰하는 MutationObserver와 원본값 추적으로 양방향 UI 복귀. 장시간 작업 중 토글해도 다른 작업 컨트롤에 영향을 주지 않게 구성.
- **핵심 엔진 보존:** IMG.LY 1.7.0, ONNX Runtime Web 1.21.0, SVG 고해상도 입력, 수동 제거 3방식, 편집 렌더링, 텍스트 이미지 생성 및 파일 저장 계산을 그대로 보존.
- **배포 구조:** `index.html` 단일 원본. 글꼴 바이너리 0개, AGPL/외부 라이선스 고지, KO/EN 사용 설명서, 릴리즈 노트 및 새 화면 스크린샷을 포함.

실제 CDN/WASM 모델 로드·Windows 로컬 파일·GitHub Pages HTTPS는 자동화 실행 환경 제약으로 **미검증**이며 배포 전 사용자의 실기기 시험이 필요합니다.
